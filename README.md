# Căn phòng lúc chạng vạng — bản thử 3D

## Chạy game trên Windows
1. Mở thư mục đã giải nén.
2. Nhấp đúp `Chay-game.bat`.
3. Cửa sổ PowerShell sẽ mở và trình duyệt tự vào game. Bấm **VÀO PHÒNG**.
4. Để dừng game, đóng cửa sổ PowerShell có tiêu đề Room game server.

Không cần cài Python. Cần kết nối Internet để tải Three.js.

## Điều khiển
- **W** tiến; **S** lùi; **A** sang trái; **D** sang phải
- **Chuột** nhìn quanh; **E** tương tác; **Esc** thả chuột
- Khi laptop bật: nhấn **1** Message, **2** Phonecall, **3** News

Bản thử dựng bằng hình học Three.js từ ảnh căn phòng; kích thước và phần khuất được ước lượng, chưa phải bản quét 3D hay game hoàn chỉnh.
