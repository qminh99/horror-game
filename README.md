# Căn phòng lúc chạng vạng — bản thử 3D

## Chạy game trên Windows
1. Mở thư mục đã giải nén.
2. Nhấp đúp `Chay-game.bat`.
3. Cửa sổ PowerShell sẽ mở và trình duyệt tự vào game. Bấm **VÀO PHÒNG**.
4. Để dừng game, đóng cửa sổ PowerShell có tiêu đề Room game server.

Không cần cài Python. Cần kết nối Internet để tải Three.js.

## Chạy game trên macOS hoặc Linux
Trong thư mục dự án, chạy `python3 serve_game.py`. Trình chạy sẽ mở game trong trình duyệt. Nhấn **Ctrl+C** trong Terminal để dừng.

## Điều khiển
- **W** tiến; **S** lùi; **A** sang trái; **D** sang phải
- **Chuột** nhìn quanh; **E** tương tác; **Space** nhảy, đứng dậy hoặc rời màn hình laptop; **Esc** thả chuột
- Khi laptop bật: nhấn **1** Message, **2** Phonecall, **3** News
- Khi ở trong tủ: nhấn **F** để bật hoặc tắt đèn tủ

## Chơi đoạn mở đầu
Bật laptop và mở **Message** để bắt đầu. Theo dõi mục tiêu trên màn hình. Khi có tiếng gõ cửa, bạn có thể chọn trốn hoặc mở cửa. Sau khi trốn thành công, chọn **Khám phá tiếp** để đi ra hành lang, phòng ngủ đối diện và nhà vệ sinh.

Từ hành lang tầng hai, đi theo biển **TẦNG 1**. Khi bước xuống hết cầu thang, rẽ phải vào bếp hoặc rẽ trái vào phòng khách. Dùng **E** để bật/tắt đèn bếp hoặc TV. Đi lại lên cầu thang để trở về tầng hai.

Bản thử dựng bằng hình học Three.js từ ảnh căn phòng. Kích thước và phần khuất được ước lượng.
